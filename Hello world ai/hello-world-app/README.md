# Hello World Application

This is a simple "Hello World" web application that prompts the user for their name and greets them. The application consists of three main files: `index.html`, `styles.css`, and `script.js`.

## Project Structure

```
hello-world-app
├── index.html      # The main HTML file containing the structure of the web page
├── styles.css      # The CSS file for styling the web page
├── script.js       # The JavaScript file for handling user interactions
├── README.md       # This documentation file
```

## How to Run the Application

1. **Clone the repository** or download the project files to your local machine.
2. Open the `index.html` file in a web browser. You can do this by double-clicking the file or by right-clicking and selecting "Open with" and then choosing your preferred browser.
3. Enter your name in the input field and click the "Greet Me" button to see your personalized greeting.

## Functionality

- The application prompts the user to enter their name.
- Upon clicking the button, the application retrieves the name and displays a greeting message in the designated paragraph element.

Feel free to modify the styles in `styles.css` or the behavior in `script.js` to customize the application further!
